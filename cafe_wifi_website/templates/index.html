Day 66 RESTful API Specification

Full programmatic access with JSON responses & live endpoint testing

This website serves both high-speed interactive UI and the full Day 66 RESTful API endpoints. Test any endpoint live below:

GET /api/cafes or /api/all

Returns a complete list of all cafes and work ratings in JSON.

GET /api/random

Returns a random cafe picked from the database.

GET /api/search?loc=Peckham

Search cafes by borough location or keyword.

POST /api/add JSON Payload

Adds a new cafe with amenities to SQLite database.

DELETE /api/delete/<id>?api-key=TopSecretAPIKey

Removes a cafe using Day 66 admin API key verification.
