# Udemy Projects

Projects built while working through the **100 Days of Code: Python Pro Bootcamp** on Udemy. Each top-level folder is a self-contained project, ranging from small automation scripts and games to a data-science regression notebook and a portfolio site.

## Projects

| Folder | Description |
| --- | --- |
| [`Morse_code_generator`](./Morse_code_generator) | Converts text to Morse code. |
| [`Multivariable+Regression+(Start)`](./Multivariable%2BRegression%2B(Start)) | Multivariable regression exercise from the course's data-science section (course starter files). Uses the pandas / scikit-learn / plotly stack listed below. |
| [`Watermarker`](./Watermarker) | Tool for adding a watermark to images. |
| [`button_presser`](./button_presser) | Small automation script. |
| [`portfolio_website`](./portfolio_website) | Personal portfolio website. |
| [`tic_tac_toe`](./tic_tac_toe) | Tic-tac-toe game. |

## Tech stack

- **Python** `>=3.12` (pinned in `.python-version`)
- **Package/dependency management:** [uv](https://docs.astral.sh/uv/) (`pyproject.toml` + `uv.lock`)
- **Data science & visualization:** pandas, NumPy, scikit-learn, matplotlib, seaborn, plotly
- **Notebook tooling:** ipykernel, IPython, nbformat, Pygments

## Getting started

```bash
git clone https://github.com/Malik-Sami/Udemy-projects.git
cd Udemy-projects

# Create the virtual environment and install locked dependencies
uv sync
```

Without uv:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install matplotlib numpy ipykernel ipython pandas plotly pygments scikit-learn seaborn nbformat
```

### Running a project

Each project lives in its own folder, so run it from there. For example:

```bash
cd tic_tac_toe
uv run python main.py
```

Entry-point filenames vary by project, so check each folder for its main script or notebook. Notebooks (such as the regression project) can be opened in VS Code or Jupyter using the `.venv` kernel.

> The `main.py` at the repo root is the placeholder generated by `uv init` and does not launch any project.
